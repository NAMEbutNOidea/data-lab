# DataLab · 本地数据可视化与统计分析工作台

导入 Excel，选样式，出论文级图，顺手把不确定度和显著性检验算完。
所有计算和绘图都在本机 conda 环境里跑，数据不出本机。

---

## 一、启动

**方式一 · 双击 `DataLab.exe`（推荐，真正的“一键”）**

双击后自动完成三件事：选解释器 → 后台起服务（无黑窗口）→ 打开浏览器。
服务已经在运行时再双击，只会把浏览器指到工作台，不会重复起进程。
启动日志写在 `logs\server.log`。

**方式二 · 双击 `run.bat`**

保留一个可见的黑窗口，适合想看实时日志的时候。

**方式三 · VSCode 里按 F5**

用 VSCode 打开 `data-lab` 文件夹，按 `F5` 选「启动 DataLab（浏览器自动打开）」。
解释器和环境变量已在 `.vscode/launch.json` 里配好，可以直接打断点调试。

**方式四 · 命令行**

```bat
cd /d "D:\A-exm\vscode_code\tools\data-lab"
"C:\Users\a3141\.conda\envs\NAMEbutNOidea\python.exe" server.py
```

关闭：`DataLab.exe` 起的服务在后台运行，需要停止时在任务管理器结束该 `pythonw.exe`，
或在命令行 `taskkill /F /IM pythonw.exe`（注意会关掉所有 pythonw 进程）。

> 换端口：`set DATALAB_PORT=9000` 后再启动。
> 不想自动弹浏览器：`set DATALAB_NO_BROWSER=1`。
> 换解释器：把路径写进 `python_path.txt` 第一行，或设 `DATALAB_PYTHON`。

## 二、界面结构

窗口化的三栏工作台，四个面板块各管一摊：

```
顶栏  DataLab · 服务状态 · 导入 / 导出 / 界面暗色
┌──────────┬──────────────────────────┬─────────────┐
│ 数据源    │ 画布（图表预览 + 下载栏）  │ 配置         │
│ 数据集与列│ ───────────────────────  │ 图表/拟合/   │
│          │ 后端 · 计算状态窗口        │ 统计/样式    │
├──────────┴──────────────────────────┴─────────────┤
│ 数据表格窗口（分页，可收起） │ 输出日志窗口          │
└──────────────────────────────────────────────────┘
```

- **后端窗口**：把服务地址、解释器版本、上次渲染耗时、数据规模四项读数和一句状态消息
  摆出来，渲染中/就绪/异常三态用右上角的状态胶囊区分，出问题先看这里。
- **不做强制流程**：四个 Tab（图表 / 拟合 / 统计 / 样式）随时可切，改列、换图型、
  跑统计互不阻塞，没有"必须走完第 3 步才能做第 4 步"的限制。
- 窄屏（<1180px）自动降级为两栏，超窄屏（<860px）单栏纵向排列。

## 四、功能

### 1. 数据导入
- 支持 `.xlsx / .xls / .csv / .tsv`，多工作表自动列出
- **自动找表头**：识别「标题行 → 说明行 → 列名行 → 单位行 → 仪器行 → 数据」这类实验报表结构，
  自动裁掉表头上下的说明行和全空列
- **自动拆单位**：`光电流(mA)` → 列名「光电流」+ 单位「mA」，坐标轴标签直接复用
- 列类型（数值/文本）、有效值数、缺失数一览

> 图形能力（18 种图型、主题、配色、拟合模型）由后端 `/api/themes` 下发，前端只按清单渲染按钮；
> 绘图指令在后端还会再归一化一次（DPI、图幅、字号、序列长度逐项收敛），
> 前端状态被改坏也不会拖死渲染进程。

### 2. 图表（18 种）
折线 · 散点 · 点线 · 误差棒 · 柱状 · 分组柱状 · 堆叠柱状 · 直方图（可叠 KDE）·
箱线图 · 小提琴图 · 残差图 · Q-Q 图 · 相关系数热力图 · 饼图
**三维**：三维散点 · 三维折线 · 三维曲面 · 三维柱状

> 后端的支持图型是唯一事实来源（`plot_engine.SUPPORTED_KINDS`），新增图型只需改一处。

**双纵轴**：给某个 Y 列点一下 chip 上的「左/右」把它指派到右轴，就会多出一根
着色的右轴（颜色默认跟随右轴第一条序列，可用 `Y₂ 轴标签/刻度` 单独设置）。
目前折线、散点、点线、误差棒、柱状五种支持；其余图型传了右轴会被静默忽略。
左右两轴的曲线仍在**同一个**图例框里，不会劈成两个。

**三维图**：选 `scatter3d` / `line3d` 时 Y 列按两两配对 —— 第 1 列作 Y、第 2 列作 Z，
可继续成对添加多条空间曲线。选 `surface3d` / `bar3d` 时每列是一条高度曲线，
X 列作为曲面/柱列的横轴，随图带色条。三维图不支持对数轴（下拉会自动禁用），
也不参与双轴。

**多子图**：布局可以用 `1×1 / 1×2 / 2×1 / 2×2` 快捷按钮，也可以自己填行数×列数
（1–4）。布局大于 1×1 时出现面板切换条，图型、X/Y 映射、标题、轴标签、对数轴都只
作用于当前选中的那一格，每格可配不同图型；角标 `(a)(b)(c)` 按位置自动编。多子图模式
下标题默认留空（自动生成的"y — x"太长，会让相邻两格挤在一起），想加就自己填。

> ⚠️ **勾选了「共享坐标轴」时，逐子图的 X/Y 刻度设置会被强制统一**——这是
> matplotlib 的共享轴语义（`sharey` 会把 `set_yscale` 传播到整组），不是 bug。
> 一旦检测到各子图刻度不一致，界面上会直接给出提示；想逐个子图单独设对数轴，
> 先取消勾选「共享坐标轴」。

**跨格子（一大两小）**：选中某一格后点「跨 2 列」或「跨 2 行」，它就会占掉相邻那格
变成一张大图，被盖住的面板自动收起（配置不丢，收回跨格时放回）。典型用法：2×2 里让
上排那格跨两列 → 上边一张宽图、下边两张小图，也就是论文里常见的 (a) 大图 + (b)(c) 小图。

**拼图板**：布局区里那块小方格图就是当前版面本身——一格一个方块，跨格的块会真实跨过去，
点任意方块弹出「子图设置」窗口：

| 控件 | 作用 |
|---|---|
| 行跨 / 列跨（步进器） | 这个子图占几行几列，1–4 任意组合（不止跨 2 格） |
| `1×1 / 1×2 / 2×1 / 2×2` | 常用尺寸一键切换 |
| 第几行 / 第几列 | 挪位置；放不下时该方向的 `+` 会自动禁用 |
| 缩略预览 | 上方实时画出整张版面，当前子图高亮并标出格数；**点任意格子**直接把它挪过去 |
| 删除子图 | 删掉这一格，空出来的位置让"未放置"的面板补上 |

改动**即时生效**：调完尺寸主窗口立刻重绘（弹窗靠右停着，左边画布整块可见），
所见即所得。点「取消」整块还原（连被跨格吃掉的面板一起回来），点「完成」或按 Esc
都保留改动，撤销栈里只落一步。

尺寸面板下方还会给出真实尺寸与宽高比，例如 `3.2 × 2.1 in（3 : 2）`——
格子占比 × 当前图幅，就是导出后那一格的物理大小。

**未放置的面板**：被大图盖住、暂时没位置的面板不会消失，在拼图板下方以 chip 形式
列出来，点一下就塞回第一个空位。「+ 新子图」在还有 1×1 空位时可用，排满了自动置灰。
每次挤掉面板都会在底部提示一声（`挤掉了 N 个面板…`），不会静默消失。

**拖拽重排**：多子图时每个子图上覆盖了一层透明热区，直接按住某个子图拖到另一个子图上
松手，两者就交换位置（大小一起换）；拖到空格子上则是移动过去。拖动时目标格有虚线高亮。
单击子图 = 选中它（右栏跟着切过去），双击子图 = 打开它的设置窗口。多子图模式下这一层
拦住了左键拖动，所以要**平移画布请按住 Shift 再拖**；滚轮缩放不受影响。

**时间轴**：日期/时间列会自动识别（列名旁有 `⏱` 标记），可以直接当 X。
后端按 ISO 字符串解析，不认识的写法会断线而不是报错。

**缩放平移**：画布上滚轮缩放（0.5×–8×，以鼠标位置为锚点）、按住拖拽平移、
双击复位，右下角显示当前倍率。缩放是纯前端 CSS transform，不会重新请求后端。

### 3. 拟合（9 种模型）
线性 · 多项式(2–6阶) · 指数 `a·e^(bx)` · 带偏移指数 · 幂函数 `a·x^b` · 对数 ·
高斯 · 洛伦兹 · 正弦

输出：各参数值 ± 标准误、方程（LaTeX / 纯文本双版本）、R²、调整 R²、
χ²、χ²/ν、RMSE、SSE、自由度、95% 预测带、残差序列。

**模型比较**：一键把 9 个模型全跑一遍，按 AIC 升序列表，给出 ΔAIC、R²、RMSE 和
一句选型结论（ΔAIC<2 视为差异不显著、2~10 有一定区分度、>10 显著更优）。
点任意一行即可套用该模型重新拟合。多项式按 `deg+1` 个参数计 k。

**公式怎么拿走**：结果里有一块 LaTeX 代码区，点代码行复制纯公式，
下面三个按钮分别复制 `纯公式` / `$$…$$` / `\begin{equation}…\end{equation}`
三种包裹形式，导进 LaTeX 或 Word 公式编辑器都不用再改。图上的公式标注用的是同一份
LaTeX（走 matplotlib mathtext），所以图、面板、复制出来的三者完全一致；
系数遇到 `1.2e-05` 这种科学计数会自动写成 `1.2\times10^{-5}`。

### 4. 统计
**描述统计**：n、均值、中位数、众数、标准差、标准误、方差、变异系数 CV/RSD、
极差、四分位、IQR、偏度、峰度、95% 置信区间。

**不确定度评定**（A/B 类）：
- A 类：`u_A = s / √n`
- B 类：`u_B = a / k`，k 由分布决定 —— 均匀 √3、三角 √6、正态按置信概率
  （68.3%→1、95%→1.96、95.45%→2、99%→2.576、99.73%→3），也支持自定义 k
- 合成：`u_C = √(Σu_i²)`
- 扩展：`U = k_p · u_C`
- 直接给结果串：`3.141 ± 0.012 (k=2, P=95%)`

**假设检验**（12 种）：单样本 t、独立样本 t、配对 t、F 检验（方差比）、单因素/多组方差分析、
Shapiro-Wilk 正态性、Levene 方差齐性、Pearson 相关、Spearman 秩相关、
Mann-Whitney U、Wilcoxon 符号秩、卡方拟合优度。
每种都给统计量、p 值、自由度、效应量（Cohen's d / η² / r²）、中文结论一句话。

### 5. 样式
8 套主题：Nature 论文 · APS 物理 · IEEE 单栏 · 现代浅色 · 深色演示 · 极简 · 笔记本 · 海报
8 套配色：NPG · Science · Lancet · NEJM · 高对比 · 灰度 · 冷色 · 暖色

可调：图幅（含单栏 3.5×2.6 / 双栏 7.1×3.5 / 方形 4×4 预设）、DPI、字号、线宽、标记大小、网格、图例位置、对数轴。

**DPI**：8 个常用档位一键切换（72 屏幕预览 · 96 · 150 草稿 · 300 期刊最低 ·
400 · 600 线条精细 · 900 · 1200），也可以直接在数字框里填任意值。
有效范围 50–1200，填超了会自动收敛并写进日志（后端 `_sanitize_spec` 是同一套区间），
顶栏右侧的 `xxx dpi` 实时跟着变。

### 6. 导出
- **图片**：PNG / SVG / PDF / EPS，**四种格式统一走浏览器下载**，
  同时服务端也落一份到 `output/`，提示里会给出完整路径
- **数据**：处理后数据另存为 xlsx / csv
- 图片命名自动带时间戳，标题里的非法字符会清洗掉

### 7. 数据变换
数据源面板的「生成新列」可以基于现有列派生新列（原列不动，重名自动加序号）：

| 变换 | 说明 |
|---|---|
| `lg` / `ln` | 取对数，非正值置空并计数 |
| 归一化（除以最大值） | 光谱/响应的常规归一化 |
| 归一化（0~1 最小-最大） | 映射到 [0,1] |
| 基线扣除（减首值） | 扣掉起始基底 |
| 基线扣除（减区间均值） | 指定行区间求均值再扣 |
| 移动平均平滑 | 居中窗口，两端只用可用点，不补零 |
| 数值求导 dy/dx | 1 或 2 阶，有 X 列时按非等间距处理 |

变换结果直接进数据集，可以当 Y 列参与绘图、拟合和统计。

### 8. 交互与快捷键
| 快捷键 | 作用 |
|---|---|
| `Ctrl+O` / `O` | 打开文件 |
| `Ctrl+S` | 导出 PNG |
| `Enter` / `Ctrl+Enter` | 执行拟合 |
| `R` | 重绘 |
| `Ctrl+Z` | 撤销（配置类操作，最多 50 步） |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| `Esc` | 关闭菜单 / 弹窗 / 浮层 |
| `?` | 快捷键说明面板 |

**鼠标**：滚轮缩放、拖拽平移（多子图时按住 Shift）、双击空白处复位、
单击子图选中、双击子图打开设置窗口、拖拽子图重排、点拼图板方块改大小。

**会话恢复**：列映射、图型、布局、主题配色、DPI、图幅这些配置存在 localStorage，
刷新自动复原；数据集本身留在服务端内存里，空状态页的「最近打开」可以点回去
（服务重启后失效，会明确提示）。

导入 `samples/示例数据_光电测量.xlsx`：

## 七、已知限制

- **依赖本机 conda 环境正常**。该环境的 OpenMP/MKL 线程层与 OpenBLAS 有冲突，
  会让 numpy 矩阵运算直接崩进程。`run.bat` 和 `server.py` 都已设置
  `MKL_THREADING_LAYER=SEQUENTIAL` 修复，`plot_engine` 里还有一层 `scipy.linalg` 兜底补丁。
  **不要删掉这两处设置。**
- 单机单用户设计：数据缓存在内存（最多 12 个数据集，LRU 淘汰），重启即清空。
- 只监听 `127.0.0.1`，局域网其他机器访问不到（有意为之）。
- 上传上限 60MB；预览分页 50 行。
- **大数据有两道闸**：前端最多载入 20 万行（超出会明确提示），
  每个序列超过 2 万点时用 LTTB 保形抽稀——抽稀会在后端状态窗口和图表 meta 里
  写明"原始 N 点 → 抽稀为 M 点"，不会再静默丢数据。形状保住了，但**逐点数值请以
  数据表格/导出文件为准**，图上不是全部原始点。
- 多子图上限 4×4、单面板 16 条序列；面板数少于格子数时多余的格子会隐藏。
- **多子图会自动缩字号**：字号是全局设置，但每格坐标区被切小了，所以后端按
  「格子较短的那条边 ÷ 2.0in」等比缩（只缩不放，下限 0.42 倍）。4×4 + 默认
  6.4×4.2in 图幅时字号会到 5.8pt 左右——能看清但不适合直接投稿，右栏会给出提示。
  想保持大字号就**先加大图幅**（4×4 建议 10×7in 以上），或者少分几格。
- **跨格按钮只做到"跨 2 列 / 跨 2 行"**（也就是拆掉 1 个邻居）。后端本身支持任意
  `rowSpan/colSpan`（`area` 字段），要做 3 格宽的大图得等按钮放开，或者直接调 API。
- **画布拖拽只绑了鼠标事件**（没有 pointer/touch，触屏拖不了）；落点靠各面板的
  绘制矩形反推格子边界，4×4 这种密集网格里会有几像素误差——只会影响"拖到相邻格"的
  手感，写坏 `area` 有兜底校验，不会把布局搞乱。
- 多子图模式下左键拖动被"移动面板"占用，**平移画布要按住 Shift 再拖**。
- 时间列只识别 `2026-10-25`、`2026/10/25`、`2026-10-25 08:30:00`、
  `2026-10-25T08:30:00`、`2026年10月25日` 这几种写法；`2026.10.25` 这种点分格式
  目前不认，会被当普通文本。
- 数据变换生成的新列会**留在内存里的这张表上**，反复对同一列做同一变换会依次得到
  `… （2）`、`… （3）`，重新导入文件才清空。
- 二阶数值求导的边界效应会影响首尾各 2 个点（两次差分的固有性质），
  中间段是精确的；点数少于 8 个时两端偏差会比较明显。
- 分类图表（柱状/箱线/小提琴等）不要设对数轴，没有意义。
- 后端有 50 条回归用例（`python tests/run_all.py`）；前端只有 CDP 验收脚本，
  属于"跑一遍看有没有挂"，不是完整的单元测试。
